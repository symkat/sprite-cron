# Sprite Cron

A proposed scheduler running on Fly.io that executes jobs on Sprites through the
Sprite exec API or a Sprite's HTTP server.

Start with the [design and research plan](docs/design.md). This repository is in
the planning phase; the service has not been implemented.

The [Go SDK research](docs/sprites-go-sdk-research.md) compares SDK and direct API
access, with source findings and reproducible local protocol probes.
