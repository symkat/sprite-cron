Application header (optional)
Optional for both public and authenticated Sprite URLs. Select a saved application header secret to send one plain-string value, e.g. X-Job-Secret: your-secret-value. Any valid HTTP header name is accepted. This value overrides a matching default header, including Authorization. Create the secret on the Credentials page; leave both fields empty if unused.


Credentials
Secrets are encrypted at rest and never returned by this page. Use Edit on a credential to replace its value once active attempts finish. Its ID stays fixed.
Create a credential
For a Sprite API token, paste the token itself without a Bearer prefix. For an application header secret, enter only its exact value, for example example-secret-value. Do not enter a header name, a Name: value line, or a JSON header map. One credential stores one value; select its ID and choose the header name on the Targets page.
